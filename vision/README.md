# CodeHer6

## Image-Based Product Recognition for Barcode-Free Retail Billing

This project uses image recognition to identify products without requiring
traditional barcodes.

## Team Modules

- `ai/` - Aanya - MobileNetV3 feature extraction
- `vision/` - Sionna - Computer vision matching
- `database/` - Sanvi - SQLite inventory
- `billing/` - San - Billing and GST
- `backend/` - Saanch - FastAPI integration
- `frontend/` - Somya - Web interface

## Sionna's Vision Module

The `vision/` module compares a feature vector generated by the AI model
with saved product feature vectors.

### Main Functions

`cosine_similarity(vector1, vector2)`

Calculates cosine similarity between two vectors.

`find_top_matches(new_vector, saved_vectors, top_k=3)`

Returns the top matching products.

`find_best_match(new_vector, saved_vectors, threshold=0.70)`

Returns the best match if the similarity is above the threshold.
